# AI HVAC Career OS

这是我的长期职业规划仓库，用来保存并持续推进「AI 化暖通/热泵/工业能源系统工程师」路线。

## 我的目标

我目前从事暖通设计，做过家庭二层小别墅的地源热泵、空气源热泵设计，也有组合式空调机组、工业转轮除湿机、嵌入式除湿机和结构设计相关经历。会 SolidWorks、CAD，专业背景是建筑环境与能源应用工程。

长期目标：未来去上海发展，五年内成为懂暖通/热泵/工业能源系统，也会用 AI、Excel/Python、BIM/CAD 自动化提高交付效率的复合型工程师，目标税前年包 30-45 万。
