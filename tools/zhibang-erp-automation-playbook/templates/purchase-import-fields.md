# 采购导入模板字段规则

ERP 官方采购导入模板是老版 `.xls`。

## 行规则

- 第 1 行：模板说明，不能删。
- 第 2 行：字段名，不能删。
- 第 3 行开始：正式数据。
- 一张采购单的第一行填写采购主信息和第一条产品明细。
- 同一张采购单的后续明细行：A 列空，B 列写 `【产品明细】`，后面只填产品字段。

## 常用列

| 列 | 字段 | 说明 |
| --- | --- | --- |
| A | 采购主题 | 第一条明细行填写 |
| B | 采购编号 | 第一条明细行填写；后续明细填 `【产品明细】` |
| C | 供应商名称 | 第一条明细行填写 |
| F | 币种 | 通常 `人民币` |
| G | 采购分类 | 通常 `常规采购` |
| H | 采购人员 | 公司默认可填指定采购人员 |
| I | 采购日期 | `YYYY-MM-DD` |
| J | 采购概要 | 简短摘要 |
| K | 产品名称 | 每条明细都填 |
| L | 编号 | ERP 产品编号 |
| M | 型号 | ERP 产品型号 |
| N | 单位 | 台、个、米等 |
| P | 数量 | 数字 |
| Q | 是否质检 | 是/否 |
| R | 单价 | 数字 |
| S | 是否含税 | 是/否 |
| T | 税率 | 如 `0.13` |
| U | 票据类型 | 不开票、普通发票、增值税专用发票等 |
| V | 折扣 | 默认 `1` |
| W | 明细优惠 | 默认 `0` |
| Y | 明细备注 | 可选 |
| AF | 品牌 | 可选 |
| AG | 入库状态 | 未入库/入库完毕 |
| AH | 收票状态 | 自动收票/收票完毕 |
| AI | 付款状态 | 自动生成/付款完毕 |
