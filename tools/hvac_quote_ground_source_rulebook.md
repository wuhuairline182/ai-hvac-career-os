# 地源热泵选型与报价 SOP

> 适用范围：世纪华泽常规别墅类地源热泵项目，系统形式为「地源热泵主机 + 每个房间风机盘管 + 地暖辐射接入」。
>
> 目标：新的 Codex / AI 对话只读取本文件，也能尽量复刻当前报价工作流，制作三份标准文件：成本与报价、方案设计书、末端配置表。
>
> 公开边界：本仓库为公开仓库。本文件保存工作流、算法、脱敏样例和校验规则，不上传客户图纸、合同、个人隐私、完整商业报价附件。

## 2. 默认工程范围

### 2.1 系统默认形式

地源热泵项目默认包含：

- 麦克维尔地源热泵主机。
- 每个房间配置风机盘管。
- 地暖辐射接入。
- 地源侧水泵、用户侧水泵、地暖辐射泵。
- 地源井系统。
- 末端水系统。

### 2.2 默认不含项

除非用户另说，默认：

- 不含税。
- 不含主电源。
- 不含吊装。
- 不含检修井制作费用。
- 不含设备基础等土建施工费用。

地源主机通常落地安装，不像空气源主机可能上屋顶，所以地源项目默认不计吊装。

## 4. 房间负荷规则

### 4.1 房间分类

常用分类：

| 房间 | 末端单位制冷量 | 主机单位制冷量 | 单位制热量 |
|---|---:|---:|---:|
| 客厅、餐厅、厨房 | 220 W/m2 | 120 W/m2 | 80 W/m2 |
| 会客室 | 250 W/m2 | 150 W/m2 | 80 W/m2 |
| 卧室、书房、次卧 | 180 W/m2 | 100 W/m2 | 80 W/m2 |

说明：

- 末端单位制冷量用于风机盘管选型。
- 主机单位制冷量用于主机总负荷表。
- 单位制热量目前按 80 W/m2。

### 4.2 负荷计算

对每个房间：

```text
末端制冷量 kW = 房间面积 × 末端单位制冷量 / 1000
主机制冷量 kW = 房间面积 × 主机单位制冷量 / 1000
制热量 kW = 房间面积 × 单位制热量 / 1000
```

方案设计书「负荷确定」表按房间类型汇总，不一定逐房间列出。

示例汇总：

| 房间类型 | 面积 | 主机单位制冷量 | 主机制冷量 | 单位制热量 | 制热量 |
|---|---:|---:|---:|---:|---:|
| 客厅、餐厅、厨房 | 85.42 | 120 | 10.25 | 80 | 6.83 |
| 会客室 | 42.55 | 150 | 6.38 | 80 | 3.40 |
| 卧室、书房 | 92.19 | 100 | 9.22 | 80 | 7.38 |
| 总计 | 220.16 |  | 25.85 |  | 17.61 |

### 4.3 同开系数

主机选型文字中，制冷量考虑同时使用系数 0.7。

```text
同开后制冷负荷 = 主机制冷量合计 × 0.7
```

示例：

```text
25.85 × 0.7 = 18.10 kW
```

重要：方案设计书「系统主机选型」必须引用当前项目已经算出的主机制冷量，不得残留旧项目数字，例如 `31.35×0.7=21.95kW`。

## 8. 地源井计算与报价规则

### 8.1 地源井数量

设计参数：

```text
夏季单位井深散热量：35 W/m
冬季单位井深取热量：30 W/m
默认单井深度：120 m
```

井数按夏季和冬季分别计算，取较大值。

当前方案书计算使用主机额定制冷/制热能力和机组效率：

```text
夏季向土壤排放热量 = 主机额定制冷量 × (1 + 1 / 制冷系数)
冬季从土壤吸收热量 = 主机额定制热量 × (1 - 1 / 制热系数)
```

当前样例：

```text
夏季排热量 = 20 × (1 + 1/5.4) = 23.71 kW
冬季取热量 = 24 × (1 - 1/4.4) = 18.49 kW
夏季总井深 = 23.71 × 1000 / 35 = 677.42 m
冬季总井深 = 18.49 × 1000 / 30 = 616.33 m
夏季井数 = 677.42 / 120 = 5.6 口 -> 6 口
冬季井数 = 616.33 / 120 = 5.1 口 -> 5 口
最终井数 = 6 口
```

井数取整规则：

- 小数部分超过 0.2 才向上加一口。
- 4.21 计 5 口。
- 4.19 计 4 口。
- 同时必须满足夏季和冬季需求，最终取两者较大值。

## 9. 成本与报价 Excel 制作规则

### 9.1 表格结构

报价 Excel 至少包含三大块：

1. 设备端造价 / 主机系统造价。
2. 末端造价。
3. 室外钻井造价 / 地源井造价。

每块都要有：

- 明细行。
- 合计行。
- 大写金额。
- 数字金额。
- 成本列和报价列，如果模板已有。

### 9.2 插入或删除行后必须检查公式

插入/删除行后，必须逐个检查：

```text
主机合计 = SUM(主机明细合价)
末端合计 = SUM(末端明细合价)
地源井合计 = 材料费小计 + 钻孔成井小计 + 土方小计
总计 = 主机合计 + 末端合计 + 地源井合计
```

不要只相信 Excel 公式。必须用脚本或手算再核一次。

## 10. 方案设计书制作规则

### 10.1 封面

封面标题必须按项目拆成两行。

示例项目名：`运城市盐湖区二层别墅地源热泵项目`

封面标题写法：

```text
运城市盐湖区二层别墅
地源热泵项目
```

不是：

```text
运城市盐湖区二层别墅地源热泵项目
空调工程
```

封面公司名和日期必须居中。日期按项目当前出具日期写。

### 10.2 项目概况

必须替换旧项目名、旧地址、旧面积。

示例：

```text
本工程为运城市盐湖区二层别墅地源热泵项目空调工程。项目位于运城市盐湖区，工程总建筑面积约为：245.21㎡。功能要求为夏季制冷，冬季制热。
```

注意：这里写建筑总面积，不写空调制冷面积。

### 10.3 室内设计参数表

「室内设计参数」表第一列房间类型，必须与「负荷确定」表房间类型一致。

示例：


### 10.4 系统主机选型段落

必须引用当前项目负荷。

示例：

```text
冷热源由地源热泵机组提供，制冷量考虑同时使用系数0.7为25.85×0.7=18.10kW，制热量为17.61kW，本次设计由麦克维尔地源热泵机组MWW200BR5-FBB(无泵)（制冷量为20kW，制冷功率为3.7kW，制热量为24kW，制热功率5.5kW）机组1台提供即可满足。
```

不得残留旧项目：

```text
31.35×0.7=21.95kW
23.01kW
```

### 10.5 方案书报价章节

报价汇总表中的「总计」必须与表格下面的「工程总造价」完全一致。

示例：

```text
主机系统造价：52640
地源井造价：16536
末端系统造价：26937
总计：96113
工程总造价：玖万陆仟壹佰壹拾叁元整  (￥：96113元)
```

日期不得残留模板日期，例如 `2026 年 4月 22 日`。

### 10.6 后三张报价明细表

方案书最后三张表必须与报价 Excel 一致：

1. 主机系统造价。
2. 地源井造价。
3. 末端系统造价。

要求：

- 字体统一。
- 不要粗细混乱。
- 合计行显示大写和数字。
- 地源井表删除 0 元行。
- 末端表风机盘管和出风口不同型号分开写。
- 出风口型号写完整 `TCR1000J配套` 这种。

## 11. 末端配置表制作规则

末端配置表用于计算房间负荷和风机盘管选型。

### 11.1 表格字段

建议保留以下字段：

| 字段 | 说明 |
|---|---|
| 楼层名称 | 一层、二层 |
| 房间名称 | 客厅、厨房等 |
| 总面积 | 房间面积 |
| 末端单位制冷量 | 用于风盘选型 |
| 末端制冷量 | 面积 × 末端单位制冷量 |
| 主机单位制冷量 | 用于主机负荷 |
| 主机制冷量 | 面积 × 主机单位制冷量 |
| 内机型号 | 自动或手动选型 |
| 数量 | 风机盘管台数 |
| 额定冷量 | 按型号查表 |
| 总负荷 | 额定冷量 × 数量 |
| 单位流量 | 按型号查表 |
| 水流量 | 单位流量 × 数量 |

### 11.2 表格外观

不要把末端配置表做成很小很扁的表格。

建议：

- 横向页面。
- A-M 列保留足够宽度。
- 标题行高度约 32。
- 表头行高度约 36。
- 数据行高度约 24。
- 文本居中、自动换行。
- 冻结窗格到 A3。

## 14. 给未来 AI 的执行指令

当用户说“做一个地源热泵项目报价/方案书/三份文件”时，未来 AI 应按以下顺序执行：

1. 确认项目月份，建立对应月份文件夹。
2. 从标准模板复制三份文件。
3. 录入房间面积，完成末端配置表。
4. 计算主机负荷、末端负荷、风机盘管数量和型号。
5. 选择麦克维尔主机；价格不足时读取产品库或询问，不能编。
6. 计算主机系统报价。
7. 计算地源井数量和报价；删除 0 元行。
8. 计算末端系统报价；不同型号分行。
9. 修改方案设计书封面、项目概况、负荷表、主机选型、地源井计算、报价章节、日期。
10. 修改方案书后面三张明细表。
11. 手算总价并与 Excel/Word 汇总交叉核对。
12. 搜索旧项目残留和乱码。
13. 最后再给用户简短汇报文件路径、总价和核查结果。

不要中途只给建议。除非缺少主机价格、模板文件不存在、项目关键信息无法推断，否则应直接执行到可交付文件。
